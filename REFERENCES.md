# References

Sources consulted while writing the conceptual material in this repository.
All explanations are written in original language; where a specific claim
comes from one of these sources, the relevant note links back here.

## Programming language (Go)

- The Go Programming Language Specification — https://go.dev/ref/spec
- Effective Go — https://go.dev/doc/effective_go
- Go standard library docs — https://pkg.go.dev/std
- The Go Memory Model — https://go.dev/ref/mem

- Cormen, Leiserson, Rivest, Stein — *Introduction to Algorithms* (CLRS), 3rd/4th ed.
- Sedgewick & Wayne — *Algorithms*, 4th ed. (https://algs4.cs.princeton.edu/home/)
- MIT OpenCourseWare 6.006 / 6.046J (Introduction to / Design and Analysis of Algorithms) — https://ocw.mit.edu
- Skiena — *The Algorithm Design Manual*

- Arpaci-Dusseau — *Operating Systems: Three Easy Pieces* — https://pages.cs.wisc.edu/~remzi/OSTEP/

## Databases

- Ramakrishnan & Gehrke — *Database Management Systems*
- Kleppmann — *Designing Data-Intensive Applications*
- PostgreSQL official documentation — https://www.postgresql.org/docs/

## Networking
